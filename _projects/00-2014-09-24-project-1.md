## Overview
Within this project, I created a python script to iterate through every file of an input directory to remove all relevant Protected Health Information (PHI)

### Regex
To complete this project, I utilized Regex to use the patterns in the naming and content of the files to recognize which files to edit and how to edit them.

### File Management - Shutil
I utilized Python's shutil library to edit, delete, and effectively navigate the input directory. 

### XLTek EpWorks
The PHI was stored within a proprietary file format: '*.iom'. This file type is encrypted unless otherwise opened using the proprietary EpWorks software. Thus, I was recquired to learn how to incorporate the EpWorks into my python path temporarily in order to effective edit and de-identify the PHI.
